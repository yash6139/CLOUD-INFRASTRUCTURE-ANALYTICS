# Cloud Infrastructure Analytics Dashboard

## Overview

This project analyzes cloud infrastructure performance and costs using Python and Pandas.

## Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Objectives

- Identify high-risk servers
- Detect scaling requirements
- Analyze departmental spending
- Recommend cloud cost optimizations

## Key Findings

- IT department had the highest infrastructure cost.
- SRV08 recorded the highest incident count.
- Multiple servers exceeded 90% CPU utilization.
- Underutilized servers were identified for potential cost savings.
